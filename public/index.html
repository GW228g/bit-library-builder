Convert my own library

Already have a Fusion 360, Vectric or Carbide Create tool library with your own feeds and speeds? Upload it and get a MillMage file. You can fine-tune any bit before you download.

🔒 Converted privately in your browser. Nothing is sent anywhere.

How do I export my library?
  1. Fusion 360: Manage → Tool Library → right-click your library → Export. Choose .json or .tools.
  2. Carbide Create: Tool Database → Export. Save the .csv file.
  3. Vectric (VCarve/Aspire): Tool Database → Export Tool Database as a .vtdb. Older .tool files work too.

Add vendor files to convert

Download a bit maker's tool library from their site, add it here, and pick the bits you own. Fusion 360 .json/.tools, Vectric .vtdb/.tool and Carbide Create .csv files work.

🔒 Same privacy: files stay on your device.

    Add to an existing library (optional)

    Pick your current .tools file and the new bits are merged into it instead of making a fresh file.

    How to install in MillMage
    1. Save the file into Documents/MillMage/ToolLibraries on your computer.
    2. In MillMage open the Tool Library and choose it (or restart MillMage).
    3. Check a few bits: vendor values are starting points, and some values (marked est.) are estimated.

    Add a bit by its specs

    Can't find your bit? Enter what's on the product page. The app finds the most similar bit in the library and keeps its chip load to suggest starting feeds and speeds. They're estimates, so test in scrap.
